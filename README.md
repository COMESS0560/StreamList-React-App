# StreamList — Week 2 User Events

An update of the existing Week 1 React/Vite StreamList project.

## Run locally
1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL printed in the terminal.
4. Run `npm run build` to check the production build.

## Demonstrate in your recording
1. On StreamList, add a title and see it immediately listed.
2. Edit its name; click Watched; select Watched filter; then Unwatch.
3. Delete a title and explain the confirmation message.
4. Refresh to show browser localStorage saving the list.
5. Navigate to Movies, Cart, and About; these pages are still planned placeholders.
6. Try a blank title to show input validation.

## Scope and privacy
This is a **client-only classroom demonstration**. No real authentication, API, streaming availability lookup, subscriptions, or payments are implemented. The watchlist stays in this browser's localStorage and is not linked to a real account. Browser data can be cleared. The demo starts with two sample titles on first use.

The previous Week 1 folder layout and navigation remain intact. No third-party icon package is required; Unicode icons provide simple visual cues.

## GitHub
Upload this folder, including package.json, index.html, src/, vite.config.js, and README.md. Do **not** upload node_modules or a .env file with secrets. Copy the URL of your own repository into your submission and paper.
